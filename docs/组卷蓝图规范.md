# 组卷蓝图规范

蓝图是一份「怎么出卷」的说明书：各大题要什么题型、几道、难度怎么配。它和试卷
是两回事——蓝图是**规则**，试卷是规则的**一次执行结果**。把规则单独存成文件，
才能做到「照着去年的规则再出一份」和「同一规则出 A/B 两套卷」。

界面上的「自动组卷」表单填的就是这份东西；每节只用一个题型时用表单最快。一个
大题要混多种题型（如综合题 + 编程题）只能写蓝图文件——表单每节只能选一个题型。

可直接改的完整示例：[`examples/组卷蓝图示例.yaml`](examples/组卷蓝图示例.yaml)

```bash
qbank paper assemble 数据结构 蓝图.yaml --dry-run   # 先看抽题结果，不写库
qbank paper assemble 数据结构 蓝图.yaml             # 确认后生成
```

---

## 最小可用的一份

```yaml
title: 2026 春季期末
sections:
  - title: 一、单项选择题
    types: [single_choice]
    count: 10
    score_each: 2
```

## 顶层字段

| 字段 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `title` | 是 | — | 试卷标题 |
| `sections` | 是 | — | 大题列表，至少一个 |
| `total_score` | 否 | 不校验 | 期望总分。填了就校验各节配分之和，对不上当场报错 |
| `seed` | 否 | 每次现取 | 随机种子。无论填不填，用掉的那个都会记在试卷上 |
| `avoid_used_within_days` | 否 | 不避 | 避开最近 N 天用过的题 |
| `statuses` | 否 | `[active]` | 只抽这些状态。默认不抽草稿题 |
| `shuffle_items` | 否 | `false` | 打乱每节内部的题目顺序 |
| `template_key` | 否 | `standard` | 导出模板标识 |
| `meta` | 否 | `{}` | 考试时长、班级、命题人……原样交给导出模板 |
| `course` | 否 | — | 课程名。命令行以参数为准，这里只作备注 |

## 大题字段

| 字段 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `title` | 是 | — | 大题标题，如「一、单项选择题（每题 2 分，共 20 分）」 |
| `count` | 是 | — | 本节题数，1–500 |
| `instructions` | 否 | 空 | 答题说明，印在大题标题下 |
| `types` | 否 | 不限 | 题型列表，如 `[single_choice]`、`[comprehensive, programming]` |
| `score_each` | 否 | 用题目自带分值 | 每题分值 |
| `difficulty_mix` | 否 | 不限 | 难度**配比**，见下 |
| `difficulties` | 否 | 不限 | 难度**范围**，见下 |
| `chapters` | 否 | 不限 | 章节路径列表，含其全部子章节 |
| `include_unchaptered` | 否 | `false` | 是否也抽未归类的题 |
| `tags_all` | 否 | — | 必须同时具备的标签 |
| `tags_any` | 否 | — | 具备任一即可的标签 |
| `source_contains` | 否 | — | 来源包含该字样，如「2025 期末」 |
| `require_answer` | 否 | `false` | 只抽有参考答案的题 |
| `shuffle_options` | 否 | `false` | 打乱选项顺序，见下 |

题型写 `QuestionType` 的英文值：`single_choice`、`multiple_choice`、`true_false`、
`fill_blank`、`short_answer`、`comprehensive`、`programming`。

## 难度：配比与范围是两个字段

老师的需求实际上有三种，所以分成两个互斥的字段：

```yaml
difficulty_mix: {2: 0.3, 3: 0.5, 4: 0.2}   # 配比：易 3 中 5 难 2（按 count=10 摊）
difficulties: [3, 4, 5]                     # 范围：中等及以上，不管分布
# 两个都不写                                  # 不限
```

`difficulty_mix` 的权重是**相对值**，`{2: 3, 3: 5, 4: 2}` 和 `{2: 0.3, 3: 0.5, 4: 0.2}`
等价。摊成整数时用最大余数法，各档道数之和**恰好**等于 `count`——不会出现
「配比里有四档，算完只剩三档」。

两个字段同时写会报错：意图不明时让人二选一，而不是替他猜。

## 选项乱序与答案

`shuffle_options: true` 时，选项按种子重排并**重新编号**成 A/B/C/D——卷子上
「C.」排在第一个位置，学生只会以为印错了。正确项跟着选项走，所以答案自然变成
新的标号。

答案字段里只写标号（`B`、`ACD`、`A、C 和 D`）时会自动换算；写了别的内容
（`B，因为栈是后进先出`）则保持原样不动——擅自改写一段话比留着一个需要人工
核对的答案更危险。

## 组不齐时会发生什么

**不会**默默少出几道。命令行报错退出、界面不给「生成试卷」按钮，并说清：

```
组不齐，原因如下：
  · 五、综合应用题·难度5（很难）需要 8 道，只排进 2 道——库内符合条件的只有 2 道
      五、综合应用题·难度5（很难）：不限难度（现在限「很难」）可多出 3 道
  · 四、简答题需要 4 道，只排进 3 道——它的候选和「五、综合应用题」是同一批题，
    而这批题总共只有 5 道，不够几节分
```

两类信息都给：**哪一条限制把题挡住了**（放宽它能多出几道），以及**是不是几节在
抢同一批题**（单看每节都够，合起来不够）。确实要接受缺额，命令行加
`--allow-partial`，界面上勾选确认。

## 章节和标签写错会报错

```
蓝图里的章节「第3章 栈与队列」在本课程里不存在。现有章节：第1章 绪论、……
```

不这么做的话，写错一个字的后果是「符合条件的题 0 道」——表现出来像是题库不够，
人会去翻题库，而真正的问题在蓝图里。

## 可复现的确切含义

**同一题库状态 + 同一份蓝图 + 同一个 seed = 同一份卷**，连选项乱序的结果都一样。

「题库状态」包括使用记录。所以设了 `avoid_used_within_days` 时，原样重跑一次
蓝图得到的是**不重题的另一套**，而不是同一套——这正是出 B 卷想要的行为。

要复现一份旧卷，看的是**卷子本身**：每道题的题面在成卷那一刻就冻结在卷子里了，
原题后来被改过、被删过都不影响。重跑蓝图不是复现旧卷的办法。

再出一套不重题的：

```bash
qbank paper variant <试卷id前8位> --seed 2026
```
