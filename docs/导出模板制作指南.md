# 导出模板制作指南

模板决定试卷**长什么样**：题号怎么排、分值印在哪、要不要密封线。内置三套够用
时不必读这篇；要改版面再往下看。

```bash
qbank paper templates                              # 看现有的
qbank paper templates --copy standard --as 我的    # 拷一套出来改
qbank paper export <试卷id> -f pdf -t 我的         # 用它导出
```

拷出来的目录在 `<数据目录>/templates/paper/我的/`（`qbank info` 会告诉你数据目录
在哪）。**同名模板会覆盖内置的那一套**，所以想整体替换 `standard` 就拷一份叫
`standard` 的。

---

## 一套模板是什么

一个目录，里面最多四个文件：

| 文件 | 作用 | 必需 |
|---|---|---|
| `paper.md.j2` | 导出 **md 与 docx** 用 | 导这两种时必需 |
| `paper.html.j2` | 导出 **html 与 pdf** 用 | 导这两种时必需 |
| `reference.docx` | pandoc 从它取 Word 样式（字体、页边距、页眉页脚） | 否 |
| `description.txt` | 一行说明，`qbank paper templates` 会显示 | 否 |

**为什么只有两份模板却有四种格式**：docx 是把 `paper.md.j2` 的输出交给 pandoc
转出来的，pdf 是把 `paper.html.j2` 的输出交给无头浏览器打印出来的。题号怎么排
只定义一次，四种格式不会打架。

缺哪份就导不了对应的格式，而且会明确报错（不会悄悄导出一份空白）：

```
模板「我的」缺少 我的/paper.md.j2，导不出 Word。它支持：html、pdf
```

## 模板里能拿到什么

模板是 [Jinja2](https://jinja.palletsprojects.com/)。顶层只有一个变量 `paper`：

| 字段 | 说明 |
|---|---|
| `paper.title` | 试卷标题 |
| `paper.meta` | 考试时长、班级、命题人…… 原样来自试卷 |
| `paper.sections` | 大题列表 |
| `paper.total_score` / `paper.question_count` | 实际的总分与题数（按题目项算，不是蓝图声明的） |
| `paper.layout` | 版面：`paper` / `full` / `answers` |
| `paper.show_questions` / `paper.show_answers` | 这个版面要不要印题目 / 答案 |
| `paper.created_at` / `paper.seed` | 成卷时间与随机种子 |
| `paper.missing_assets` | 有几张图没找到（卷头可以提醒一句） |

每个 `section`：

| 字段 | 说明 |
|---|---|
| `section.number` / `section.title` / `section.instructions` | 序号、标题、答题说明 |
| `section.items` | 题目列表 |
| `section.count` / `section.total_score` | 本节题数与总分 |
| `section.objective_items` / `section.subjective_items` | 客观题 / 主观题（答案卷排版用） |

每个 `item`：

| 字段 | 说明 |
|---|---|
| `item.number` | **全卷连续**题号 |
| `item.index` | 本节内序号（想按节编号时用） |
| `item.score` / `item.type_label` / `item.difficulty` | 分值、题型中文名、难度 |
| `item.stem` | 题干（Markdown） |
| `item.options` | 选项，每个有 `label` / `content` / `is_correct`。**已按乱序重排并重新编号** |
| `item.answer` / `item.explanation` / `item.rubric` | 答案、解析、评分标准 |
| `item.compact_answer` | 客观题的一行式答案；主观题是空串 |
| `item.sub_questions` | 综合题的小问，每个有 `label` / `score` / `stem` / `answer` / `rubric` |
| `item.programming` | 编程题的 `language` / `function_signature` / `starter_code` / `test_cases` |
| `item.is_objective` / `item.shuffled` | 是不是客观题；选项是否被打乱过 |

**所有文本字段都是 Markdown 原文**，不是 HTML。在 html 模板里要过 `md` 过滤器。

### 三个过滤器

| 过滤器 | 作用 |
|---|---|
| `md` | Markdown → HTML（公式转 MathML）。**只在 html 模板里用** |
| `g` | 分值去掉多余小数：`2.0` → `2`。卷子上印「2.0 分」像是程序没写完 |
| `cn` | 数字 → 中文：`1` → `一`。超过十用阿拉伯数字 |

## 最省事的改法：继承

不要从空白开始。继承内置模板，只改自己要改的那块：

```jinja
{% extends "standard/paper.html.j2" %}

{% block page_size %}B5{% endblock %}
{% block body_size %}10pt{% endblock %}
{% block extra_styles %}
.paper-head h1 { color: #036; letter-spacing: 0.1em; }
{% endblock %}
```

`standard/paper.html.j2` 预留的块：

| 块 | 默认值 | 用途 |
|---|---|---|
| `page_size` | `A4` | 纸张 |
| `page_margin` | `18mm 16mm` | 页边距 |
| `body_size` / `print_size` / `title_size` | `11.5pt` / `11pt` / `17pt` | 字号 |
| `styles` | 整段 CSS | 整体换掉（一般不用） |
| `extra_styles` | 空 | **追加** CSS，最常用 |
| `header` | 卷头 | 换卷头（`exam` 就是改了这块） |
| `body` | 题目正文 | 换正文排版 |
| `answer_key` | 答案区 | 换答案卷排版 |

`standard/paper.md.j2` 预留了 `header` / `body` / `answer_key` 三块。

## Word 的样式怎么改

Word 的版面不由模板控制，由 **`reference.docx`** 控制——那就是一份普通的 Word
文档，pandoc 从里面取字体、标题样式、页边距、页眉页脚。改它不需要懂任何模板语法：

```bash
pandoc -o reference.docx --print-default-data-file reference.docx
```

把它放进模板目录，用 Word 打开，改「正文」「标题 1」「标题 2」这些样式，存盘。
下次导出 docx 就用你的版面了。没有这个文件时用 pandoc 的默认样式。

## 打印相关的几个坑

**页码不能写在 CSS 里。** Chromium 不支持 `@page { @bottom-center { content: counter(page) } }`，
写了不会报错，只是永远不出现。页码由导出器通过浏览器的页脚模板注入，模板里
不用管。

**一道题不要被拆到两页。** 内置模板在 `.item` 上写了
`break-inside: avoid`。超过一页高的题浏览器会忽略它，这是预期行为。

**大题标题不要孤零零留在页底**：`break-after: avoid`。

**密封线要靠 `position: fixed`**——Chromium 打印时固定定位元素会在每一页重复。
但它占的那条带子**必须**由 `body` 的 padding 让出来，否则正文会从它底下穿过去，
印出来是一条划掉半张卷子的虚线（`exam` 模板踩过这个坑，注释里写着）。

**长代码行要折断**：打印没有滚动条，`overflow-x: auto` 在纸上等于直接裁掉。
内置模板给 `pre` 加了 `white-space: pre-wrap; word-break: break-word`。

## 自包含是硬要求

html 模板**不能引用任何外部资源**——没有外链 CSS、没有外链字体、没有 `<script>`。
理由有两个：发给学生的单文件要能断网打开；Chromium 打印 PDF 时不会等网络请求，
取不到的资源不会报错，只会印出一个缺图少样式的版面。

图片不用模板操心：`asset://` 在建上下文时就已经按目标形式换好了（HTML 换成
`data:` 内联，Markdown 换成旁挂相对路径，Word 换成绝对路径）。

公式走 MathML，浏览器原生渲染，不需要 KaTeX 的 JS 与字体。

## 写错了会怎样

模板里引用一个不存在的字段会**当场报错**，而不是渲染成空白：

```
jinja2.exceptions.UndefinedError: 'ItemContext object' has no attribute 'scores'
```

这是有意的（`StrictUndefined`）。默默渲染成空白的后果是老师印完一百份才发现
分数没了。
