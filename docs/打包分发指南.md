# 打包分发指南

把 qbank 打成一个双击即用的应用，给不懂命令行的人用。

```bash
pip install -e ".[web,desktop,package]"
pyinstaller packaging/qbank.spec --noconfirm
```

产出在 `dist/`：

| 平台 | 产物 | 怎么用 |
|---|---|---|
| macOS | `dist/qbank.app` | 双击 |
| Windows | `dist/qbank/` | 运行里面的 `qbank.exe` |
| Linux | `dist/qbank/` | 运行里面的 `qbank` |

---

## 捆了什么，没捆什么

| | 捆了吗 | 体积 | 为什么 |
|---|---|---|---|
| pandoc | **是** | 约 110 MB | Word 的导入与导出都靠它，而目标用户手里的历年真题基本都是 .docx |
| pywebview | 是 | 约 2 MB | 没它就只剩命令行 |
| migrations | 是 | 很小 | 少了它，打包版打开旧题库时不会升级表结构，而且一声不吭 |
| playwright | **否** | 约 140 MB | 只服务于 PDF 导出，而 PDF 有现成退路 |
| 浏览器内核 | 否 | 约 130 MB | 打不进去；运行时靠系统装的 Chrome |
| psycopg | **否** | 约 19 MB | 打包版是给单机用户的，题库就是本地那个 SQLite 文件 |

所以**打包版连不了 Postgres**：给它设 `QBANK_DATABASE_URL` 会报
`ModuleNotFoundError: No module named 'psycopg'`。要跑 Postgres 就别用打包版，按
[Web 部署指南](Web部署指南.md)装源码——那是服务器上的事，本来也不需要双击运行。

成品约 170 MB。要带上 PDF 支持：

```bash
QBANK_BUNDLE_PDF=1 pyinstaller packaging/qbank.spec --noconfirm
```

注意即使这样，**浏览器内核仍然不在包里**——用户机器上要有 Google Chrome 或
Edge，或者自己执行过 `playwright install chromium`。

没有 PDF 时并不是死路：导出 HTML 再用浏览器的「打印为 PDF」，版面完全一样
（PDF 本来就是这么生成的）。`qbank doctor` 在打包版里会直接这么说，而不是叫人
去 `pip install`——包是只读的，那条路走不通。

## 打包版也是命令行

传了参数就当命令行跑。不这么做的话，打包版就只剩一个窗口，而 `doctor`
（出问题时第一个要跑的）和 `bundle export`（唯一的备份手段）都够不着了：

```bash
dist/qbank.app/Contents/MacOS/qbank doctor
dist/qbank.app/Contents/MacOS/qbank bundle export -o 备份.qbz
```

Windows 上直接 `qbank.exe doctor`。

## 容易踩的坑

**运行时按路径读的数据文件必须显式收。** PyInstaller 默认只收 `.py`。漏一个
就会在**用到的那一刻**才炸，而构建过程一个警告都没有。实测踩过：少了
`latex2mathml/unimathsymbols.txt`，Markdown 导出一切正常，一导 HTML 就
`FileNotFoundError`。

spec 里显式收了这几个包的数据：`qbank`（模板与静态文件）、`pypandoc`、
`latex2mathml`、`webview`、`alembic`、`markdown_it`。加新依赖时要想一想它有没有
自己的数据文件——`tests/unit/test_layering.py` 里有一条测试守着这张清单。

**冻结后 `__file__` 推不出项目根。** 源码不在磁盘上的源码树里了。
`qbank.app._project_root` 会认 PyInstaller 解包出来的 `sys._MEIPASS`。不处理的
话，`alembic.ini` 找不到，而 `_head_revision()` 吞掉异常返回 `None`——于是打包版
**永远不跑数据库迁移**，升级后打开旧题库，表结构还是旧的，程序一声不吭。

**macOS 上窗口要能连本地 HTTP。** `Info.plist` 里开了
`NSAppTransportSecurity.NSAllowsLocalNetworking`，否则系统会直接拦掉窗口对
`http://127.0.0.1` 的请求。

**不要做成 console 程序。** spec 里 `console=False`，否则 macOS 上双击会先弹一个
终端窗口。命令行用法不受影响——直接执行 `.app` 里的那个二进制即可。

## 签名与公证（未做）

macOS 上未签名的 `.app` 第一次打开会被 Gatekeeper 拦住，用户要右键「打开」
或者去「系统设置 → 隐私与安全性」放行。要免掉这一步需要 Apple 开发者账号做
签名与公证，本项目没有做。Windows 上同理，SmartScreen 会提示「未知发布者」。

## 数据放在哪

打包版和 pip 安装版用的是**同一个数据目录**（`qbank info` 会打印具体位置），
所以两者可以来回切换，题库是同一份。
